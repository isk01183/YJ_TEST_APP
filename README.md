# 충전중 표시 앱 (ChargingApp)

인터넷 연결 없이 완전히 오프라인으로 동작하는 안드로이드 앱입니다.
설치 후 앱을 열지 않아도 백그라운드에서 항상 실행되며, 충전기를 연결하면
화면(및 잠금화면)에 "충전중"을 표시합니다.

## 이 앱이 하는 일

1. **항상 백그라운드 실행**: 설치 후 최초 1회 실행하면 포그라운드 서비스가 시작되고,
   기기를 재부팅해도 자동으로 다시 시작됩니다.
2. **충전 감지 시 "충전중" 표시**: 충전 케이블을 꽂으면 화면 위에 배지 형태로 "충전중"이 표시됩니다.
3. **잠금화면 변경**:
   - 잠금화면 배경(월페이퍼)이 자동으로 "충전중" 텍스트 이미지로 바뀝니다.
   - 동시에 전화 수신 화면처럼, 잠금화면 위에 전체화면으로 "충전중" 화면이 표시됩니다.
   - 케이블을 뽑으면 자동으로 사라집니다.
4. **인터넷 미사용**: 코드 어디에도 네트워크 통신 코드가 없고, `usesCleartextTraffic="false"`로
   명시되어 있습니다. Wi-Fi/데이터 없이 100% 동작합니다.

## ⭐ APK 빌드 방법 A — GitHub Actions로 자동 빌드 (Android Studio 설치 불필요, 가장 쉬움)

Claude 채팅 환경에는 Android SDK가 없어서 여기서 바로 `.apk` 파일을 만들어드릴 수 없습니다.
대신 이 프로젝트에 GitHub이 대신 컴파일해주는 자동화 설정(`.github/workflows/build.yml`)을
이미 포함해뒀습니다. 순서는 다음과 같습니다.

1. GitHub에서 새 저장소(Repository)를 만듭니다 (Public/Private 상관없음).
2. 이 압축을 풀어서 나온 `ChargingApp` 폴더 전체를 그 저장소에 업로드/푸시합니다.
   - 웹에서: 저장소 페이지 > `Add file` > `Upload files` 로 폴더 내용을 드래그 앤 드롭
   - 또는 터미널에서:
     ```
     cd ChargingApp
     git init
     git add .
     git commit -m "최초 커밋"
     git branch -M main
     git remote add origin https://github.com/사용자명/저장소명.git
     git push -u origin main
     ```
3. 저장소 상단 **Actions** 탭으로 이동하면 "Build APK" 워크플로가 자동으로 실행됩니다
   (몇 분 소요, 무료).
4. 빌드가 초록색 체크(✔)로 끝나면 해당 실행(run) 페이지 하단의
   **Artifacts** 섹션에서 `ChargingApp-debug-apk` 를 클릭해 다운로드합니다.
   압축을 풀면 진짜 설치 가능한 `app-debug.apk` 파일이 들어있습니다.
5. 그 apk 파일을 휴대폰으로 전송(카카오톡 나에게 보내기, 이메일, USB 등) 후 눌러서 설치하면 됩니다.
   (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

이 방식은 로컬 PC에 아무것도 설치할 필요 없이, **완성된 실제 APK 파일**을 손에 넣는 가장 빠른 방법입니다.

## APK 빌드 방법 B — Android Studio 로컬 빌드 (PC 필요)

1. [Android Studio](https://developer.android.com/studio) 설치 (최초 설치 시에만 인터넷 필요)
2. `File > Open` 으로 이 `ChargingApp` 폴더 전체를 엽니다.
3. Gradle Sync가 끝날 때까지 기다립니다 (최초 1회만 인터넷으로 의존성을 받습니다).
4. 상단 메뉴 `Build > Build Bundle(s) / APK(s) > Build APK(s)` 클릭
5. 빌드가 끝나면 `app/build/outputs/apk/debug/app-debug.apk` 파일이 생성됩니다.
6. 이 APK를 폰으로 옮겨서 설치합니다 (출처를 알 수 없는 앱 설치 허용 필요).

> 참고: 빌드하는 "PC"에는 최초 1회 인터넷이 필요하지만(Gradle 라이브러리 다운로드),
> 완성된 APK 자체는 휴대폰에서 인터넷 없이 완전히 독립적으로 동작합니다.

## 설치 후 반드시 해야 할 설정 (앱 최초 실행 시 안내됨)

앱을 처음 열면 아래 3가지 권한 허용 버튼이 나옵니다. **모두 눌러서 허용**해주세요.
이걸 안 하면 안드로이드 OS가 배터리 절약을 위해 앱을 강제 종료시킬 수 있습니다.

1. **다른 앱 위에 표시** 허용 → 충전 중 화면 위에 텍스트를 띄우기 위해 필요
2. **배터리 최적화 무시** 허용 → 백그라운드에서 계속 실행되기 위해 필요
3. **알림 권한** 허용 (Android 13 이상) → 잠금화면 위에 전체화면을 띄우기 위해 필요

### 제조사별 추가 설정 (중요)

삼성/샤오미/화웨이 등 일부 제조사는 자체적으로 더 강하게 백그라운드 앱을 종료시킵니다.
완전히 안정적으로 "항상 작동"하게 하려면 기기 설정에서 아래 항목도 추가로 확인해주세요.

- 설정 > 배터리 > 백그라운드 사용 제한 > 이 앱을 "제한 없음"으로 설정
- (삼성) 설정 > 배터리 > 절전 모드에서 앱 제외
- (샤오미 MIUI) 자동 시작(자동 실행) 허용 + 잠금화면 표시 앱에 추가

## 알아두어야 할 기술적 한계

- 일반 앱(비-시스템 앱)은 안드로이드 보안 정책상 "100% 강제 종료 절대 불가"를 보장할 수 없습니다.
  위 권한들을 모두 허용하면 실질적으로 항상 켜져 있지만, 완전한 보장은 기기 제조사(시스템 앱) 수준의
  권한이 필요합니다.
- 잠금화면을 완전히 다른 화면으로 "교체"하는 기본 잠금화면 앱이 되려면 별도의 시스템 레벨 인증이 필요해
  일반 앱으로는 제공하지 않았습니다. 대신 배경화면 변경 + 전체화면 오버레이 두 가지 방식으로
  사실상 동일한 효과(잠금화면에서 "충전중" 문구 확인)를 구현했습니다.

## 프로젝트 구조

```
ChargingApp/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/example/chargingapp/
│       │   ├── MainActivity.kt              # 최초 실행 시 권한 요청 화면
│       │   ├── BootReceiver.kt              # 재부팅 시 서비스 자동 시작
│       │   ├── ChargingForegroundService.kt # 항상 실행되는 핵심 서비스
│       │   └── ChargingFullScreenActivity.kt# 잠금화면 위 전체화면 "충전중"
│       └── res/                             # 레이아웃, 문자열, 색상, 아이콘
├── build.gradle
└── settings.gradle
```
